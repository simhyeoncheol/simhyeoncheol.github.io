프로젝트 소개

(주)더바디채널의 심박 기반 운동 기록 · 소셜 앱입니다.
스마트 워치로 측정한 심박 · 걸음 · 칼로리 · 경로를 기록하고, 피드 · 랭킹 · 챌린지로 회원끼리 함께 운동하도록 만드는 서비스로, 저는 앱과 백엔드 개발을 맡았습니다.

주요 기능

  • Apple Watch HKLiveWorkoutBuilder 기반 워치 단독 측정 · 폰 동기화, 삼성헬스 · Galaxy Watch 심박 연동
  • 심박 기반 Keytel 칼로리 공식 적용, 시간 가중 평균 심박 계산, 실기기 없이 워치 연동을 검증하는 테스트 환경 구축
  • 피드 · 스토리 · 팔로우 · 러닝 매칭 · 모임 · 랭킹 · 30일 출석 챌린지 · DM 등 소셜 기능, 카카오맵 경로 표시
  • 백엔드 DB 스키마 재설계 및 데이터 이관 — 동시 가입 시 id 충돌(max(id)+1 → AUTO_INCREMENT) 해결
  • 운동기록 bulk API · 랭킹 집계 배치 · ERP 출결 연동 챌린지 개발, HTTP 에러 코드 정상화
  • 바디채널 계정 로그인 통합, Google Play 심사 반려 대응
