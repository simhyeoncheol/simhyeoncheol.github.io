통계 대시보드

사용자가 위젯 배치를 직접 구성하고, 위젯마다 상세 데이터를 조회·내보내는 병원 통계 대시보드입니다.

Web반응형

수익 종합현황판: 보드별 위젯 그리드와 동적 조회 조건

레이아웃 편집 모드: 드래그 이동, 리사이즈, 표시/숨김

숨긴 위젯 표시와 사번 · 보드 단위 서버 저장

보드 전환과 개인 설정 초기화

위젯 상세 화면: 조회 조건 유지, 데이터 보기

데이터 상세보기: 검색, 정렬, 페이지네이션, 엑셀 내보내기

조회 조건: 진료과 · 병동 목록 API

자동 새로고침: 클릭 재조회, 우클릭 간격 설정

프로젝트 소개

병원 정보 시스템의 진료비, 내원 환자, 병상이용률, 재원일수, 수술건수 등을 차트 위젯으로 보여 주는 사내 웹 대시보드입니다. 보드(전체 · 인원 종합현황판 · 수익 종합현황판)마다 위젯 구성이 다르고, 사용자는 위젯 배치와 크기, 표시 여부를 직접 바꿀 수 있으며 그 설정은 사번 단위로 서버에 저장됩니다. 위젯 제목을 누르면 상세 화면에서 차트를 크게 보고 원본 데이터를 표로 조회하거나 엑셀로 내려받을 수 있습니다.

주요 구현 기능

01

사용자별 UI 커스터마이징

환경설정 모드를 켜면 react-grid-layout 그리드에서 위젯을 드래그로 옮기고 5방향 핸들로 크기를 조절하며(최소 3×3), 위젯별로 표시/숨김을 전환합니다. 숨긴 위젯은 편집 모드에서만 반투명으로 보이고 일반 모드에서는 빠집니다.

02

레이아웃 서버 저장과 복원

편집 모드를 끄는 시점에 브레이크포인트별 레이아웃(/api/config/layouts)과 표시 위젯 목록(/api/config/visibleGraph)을 사번 · 보드 단위로 저장합니다. 진입 시 /api/layout, /api/visibleGraph로 복원하고, 저장값이 현재 위젯 목록과 맞지 않으면 기본 구성으로 돌아갑니다. 초기화는 /api/deleteConfig로 개인 설정을 지우고 기본 레이아웃을 다시 받습니다.

03

위젯 상세 화면

위젯 제목을 누르면 /detailpage?chartId=…로 이동해 같은 조회 조건으로 차트를 크게 보여 줍니다. "데이터 보기"는 차트의 원본 데이터(<차트 API>_Data)를 표로 띄우고, 공통코드(listValue/smpl)로 컬럼명 매핑과 표시 여부를 정합니다. 컬럼 정렬(숫자 / 한글 localeCompare), 전체 컬럼 검색, 10~100행 페이지네이션, ExcelJS 엑셀 내보내기(헤더 서식, 날짜 정규화)를 지원합니다.

04

보드별 동적 조회 조건

조회 조건 항목을 보드별 메타데이터(/api/parameters)로 받아 렌더링하고, 진료과 · 병동 목록은 각각의 API로 채웁니다. 일 · 월 · 분기 단위에 맞춰 시작일과 종료일을 계산해 모든 위젯에 같은 쿼리 파라미터로 전달하며, 조회 조건은 세션에 저장돼 상세 화면과 오갈 때 유지됩니다. 새로고침 간격(초)을 설정하면 주기적으로 다시 조회합니다.

기술적 과제와 해결

외부 HTML 차트 위젯의 드래그 · 리사이즈

과제차트 대부분은 차트 서버가 렌더링한 HTML을 <object>로 임베드하는 구조라, 그리드 편집과 함께 동작해야 했습니다.

분석임베드된 문서가 마우스 이벤트를 가져가 드래그 중 포인터를 놓치고, 위젯 크기를 바꿔도 내부 차트는 이전 크기로 남습니다. 긴 대시보드에서는 아래쪽 위치로 끌어 놓기도 어려웠습니다.

해결드래그 · 리사이즈 동안 모든 임베드에 pointer-events: none을 걸고, 리사이즈가 끝나면 임베드 문서의 window에 resize 이벤트를 보내 차트를 다시 그리게 했습니다. 드래그 중 포인터가 화면 위 · 아래 50px 안에 들어오면 그리드를 자동 스크롤합니다. 조회 조건이 바뀌면 각 임베드의 URL 쿼리만 교체해 다시 불러옵니다.

저장된 레이아웃의 검증과 위젯 추가 대응

과제서버에 저장된 개인 레이아웃은 위젯 구성이 바뀐 뒤에도 그대로 남아 있을 수 있습니다.

분석필수 값(breakpoint, i, x, y, w, h)이 빠지거나 숫자가 아닌 항목, 같은 id의 중복 항목이 섞이면 그리드가 깨집니다. 새로 추가된 위젯은 저장된 레이아웃에 위치가 없습니다.

해결불러온 레이아웃을 항목 단위로 검증해 잘못된 항목은 버리고 중복 id는 마지막 값으로 교체합니다. 저장된 표시 목록에 없는 위젯 id는 걸러 내고, 레이아웃에 없는 새 위젯은 기존 위젯 아래에 3×3 크기로 컬럼 수에 맞춰 자동 배치합니다.
