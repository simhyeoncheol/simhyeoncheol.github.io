프로젝트 소개

러닝 · 웨이트 · 요가 · 등산까지 한 곳에 담는 소셜 운동 앱입니다.
iPhone 과 Apple Watch 가 하나의 운동을 나눠 보도록 설계해, 어느 쪽에서 시작해도 양쪽이 같은 화면을 보이고 기록은 하나만 남습니다.

주요 기능

  • 4개 카테고리 11개 종목을 하나의 Activity 모델로 통합 — 새 종목은 정의 한 줄로 추가
  • 백그라운드 GPS 추적, 종목별 지터 필터, 자동 일시정지, 1km 음성 스플릿, 실시간 경로 지도
  • WatchConnectivity 브리지를 Expo 네이티브 모듈로 직접 구현 — 폰/워치 어느 쪽에서 시작해도 일시정지 · 종료가 상대에게 전달되는 미러링
  • 친구 · 피드 · 응원 · 챌린지, 러닝 모임 '신호'(장소 · 정원 · 사진 · 집결지 지도), 그룹런 실시간 위치 공유
  • 오프라인 우선 저장(로컬 → 동기화 큐 → Firestore), Cloud Functions 푸시 알림, Apple 로그인
  • 순수 로직 테스트 35개 + Firestore 보안 규칙 에뮬레이터 테스트 19개
