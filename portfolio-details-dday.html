프로젝트 소개

디데이 · Apple 캘린더 일정 · 미리 알림을 메뉴바 앱 하나와 데스크톱 위젯 11종으로 보여 주는 macOS 생산성 앱입니다. 앱을 열지 않고도 위젯에서 일정을 보고 할 일을 완료 처리할 수 있습니다.

주요 구현 기능

01

설정 가능한 인터랙티브 위젯

App Intents(SelectDDayIntent)로 위젯마다 디데이 · 분류 · 잠금을 설정하고, 스와이프가 없는 위젯에서 ◀▶ 버튼(ShiftDDayIntent)으로 페이지를 순환합니다.

02

잠금 위젯 + 생체 인증

위젯은 인증 UI 를 띄울 수 없어 dday://unlock 딥링크로 앱을 열고, LAContext(Touch ID · Mac 암호) 성공 시 해당 위젯만 30초 해제합니다. 재잠금 시각은 타임라인에 미리 배치합니다.

03

EventKit 읽기 / 쓰기 · 위젯에서 완료 체크

ToggleTodoIntent 가 캐시를 먼저 바꿔 즉시 반영한 뒤 EKReminder 를 저장하고, 위젯에서 쓸 수 없으면 대기 큐 + DistributedNotificationCenter 로 앱이 이어 처리합니다.

기술적 도전 및 해결

앱과 위젯(별도 프로세스) 간 데이터 공유 · 갱신

문제위젯 확장은 별도 프로세스라 앱 데이터를 직접 볼 수 없고, 다시 그릴 시점도 따로 정해야 했습니다.

해결App Group UserDefaults 에 JSON 으로 공유하고 저장할 때마다 reloadAllTimelines() 를 호출, 일정 위젯은 min(30분, 자정) 시각에 다시 불러오도록 했습니다.

한국 음력 설날 오차

문제Foundation 의 .chinese 달력은 2027 · 2028년 설날을 한국 음력과 하루 다르게 계산합니다.

해결보정 테이블을 두고 전용 테스트로 검증했습니다.
