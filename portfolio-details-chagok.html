iOS — Screen Time 권한 · 허용 앱 선택 · 세션 중 차단(Shield)

Chrome 확장 (MV3) — 차단 페이지 · 허용 목록 팝업

프로젝트 소개

여러 기기에서 이어지는 공부 스톱워치입니다. 공부 세션 동안 기기마다 방해되는 앱과 사이트를 차단하며, 웹 · 모바일 · 데스크톱 · 브라우저 확장이 하나의 Supabase 백엔드와 TypeScript 공용 패키지(도메인 · 동기화 · 차단 규칙)를 공유하는 pnpm 모노레포로 구성했습니다.

주요 구현 기능

01

멱등 오프라인 동기화 엔진

모든 명령을 outbox(IndexedDB / SQLite)에 먼저 기록한 뒤 commandId 로 재전송하고, expectedVersion 낙관적 동시성으로 충돌 시 서버를 우선합니다.

02

OS 별 차단 엔진 공통 계약

BlockEngine 계약과 decideApply 가 버전 · 만료 · 권한 상태를 판정하고, BlockCoordinator 가 서버 지시를 적용 · 보고합니다. iOS FamilyControls, Android 접근성 서비스, macOS 에이전트, Windows, Chrome 확장이 같은 계약을 구현합니다.

03

시간대 · DST 인지 통계

이벤트 구간만 저장해 자정을 넘는 구간은 날짜별로 나누고 겹친 구간은 합집합으로 계산, 서버 daily_stats 와 클라이언트 결과를 서울 · 뉴욕 시간대로 대조 검증했습니다.

기술적 도전 및 해결

두 기기 동시 시작 시 세션 중복

문제두 기기가 동시에 시작하면 활성 세션이 2개 생기고, 재전송 시 이벤트가 중복될 수 있었습니다.

해결profiles 행 FOR UPDATE 잠금 + 부분 유니크 인덱스 + commandId 기본키로 막고, 실제 PostgreSQL 17 동시 연결 테스트에서 START 12건 → 활성 세션 1건, 같은 commandId 8건 → 이벤트 1건을 확인했습니다.

Electron 데스크톱 셸이 200MB 이상

문제Electron 기반 데스크톱 셸이 너무 무거웠습니다.

해결macOS 는 Swift + WKWebView(약 2.2MB), Windows 는 C# + WebView2(약 4.2MB)로 교체하고 window.chagokDesktop 계약으로 웹 화면을 그대로 재사용했습니다.

프로젝트 성과

  • Windows CI 단위 테스트 278 / 278 · 데스크톱 기능 테스트 94건 통과
  • Vitest + 실제 PostgreSQL 17(PGlite) 기반 도메인 · DB(RLS / RPC) · 동시성 테스트 약 200건, 플랫폼별 실행 캡처로 동작 검증
