프로젝트 소개

여러 기기에서 이어지는 공부 스톱워치입니다.
과목을 고르고 타이머를 시작하면 공부 중에는 방해되는 앱과 사이트를 막아 주고, 기록은 웹 · 모바일 · Mac 어디서든 이어집니다.

주요 기능

  • 과목별 공부 타이머, 일 · 주 · 월 통계와 캘린더 · 차트, 게스트 잠금 화면
  • 오프라인 큐(outbox) + 멱등 재전송 동기화 엔진 — 활성 세션은 하나만, 다른 기기에서 이어받기, 자정 기준 일별 분배
  • 플랫폼별 차단 엔진: Mac(Swift 에이전트 + WKWebView 앱), Android 접근성 서비스, iOS FamilyControls, Chrome 확장
  • Supabase 스키마 · RLS · RPC 를 실제 Postgres 17(PGlite)에 적용해 테스트로 검증
  • pnpm 모노레포로 도메인 · 동기화 · 차단 규칙을 패키지로 분리, 설계 결정을 문서로 기록
